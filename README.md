# Executive Steering Committee Boardroom Portal

An interactive 3D Executive Steering Committee Boardroom portal built with Three.js, WebGL PBR rendering, and modern spatial navigation. The portal gives committee members access to eight executive applications in one 3D environment.

## Features

- Three.js PBR rendering, studio lighting, and procedural reflections.
- Interactive portal selection with hover feedback and camera focus.
- Boardroom environment with architectural details and furnishings.
- GLTF models with procedural avatar fallback.
- Validated HTTPS navigation to authorized GitHub Pages destinations.

## Development and Testing

Run tests with `npm run test` and create a production build with `npm run build`.

The repository is configured for GitHub Pages deployment through `.github/workflows/deploy.yml`.
